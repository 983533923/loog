# shirt-logo-placement

给服装商品图**批量添加品牌 logo** 的 Codex 技能：把 logo 贴到衣服的胸口位置，只做局部像素合成——衣服的颜色、款式、面料质感，以及背景、文字、尺码表、其他衣服、衣服自带的徽章，全部保持原样。

## 能做什么

- 扫描项目目录（按商品款式分文件夹，内含「主图」「详情图」等子文件夹），批量处理其中的图片；
- 逐张判断是否适合加 logo，把 logo 贴到衣服胸口；
- **同一款式下所有图片**（不同颜色、主图与详情图）使用统一的 logo 相对大小，保证视觉一致；
- 处理完直接覆盖原图，不额外生成新文件。

## 贴图规则

以**衣服横向宽度 W** 为唯一尺度基准（按图片宽度取比例会明显不一致）：

| 项目 | 规则 |
| --- | --- |
| logo 宽度 | 0.085–0.09 × W（默认 0.088） |
| 水平位置 | 穿着者左胸（观者视角右前襟），门襟右侧约 0.1 × W |
| 垂直位置 | logo 中心在领口最高点下方 0.28–0.37 × W |
| 朝向 | 跟随衣服平面倾斜（掀开、托举、侧身展示时常见 5°–15°） |
| 缩放 | **严格等比**，保持素材宽高比，不拉伸 |
| 一致性 | 同款各颜色、各图片统一用同一个比例参数 |

遇到「模特背对镜头、把衣服正面掀开展示」这类情况，正面会被左右翻转，logo 相应落在观者视角的另一侧——按衣服结构判断，而不是记固定的左右。

## 跳过哪些图

背面展示图、局部特写（只拍领口/袖口/拉链/面料）、纯文字或参数图（尺码表、面料说明）、胸前已有品牌 logo 或印花的图、非上衣（裤子/包/鞋/配饰），以及胸口被遮挡或角度过侧看不清的图。

一件图里有多件同款、被画面裁掉一半的衣服，属于**要处理**的情况，不会跳过。

## 安装

把 `shirt-logo-placement` 整个文件夹复制到 Codex 的技能目录：

```powershell
Copy-Item -Recurse -Force .\shirt-logo-placement "$env:USERPROFILE\.codex\skills\"
```

然后新开一个对话，技能即可被识别。

## 使用

把**项目根目录**和**一张 logo 图片**交给 Codex，说一句：

> 用这个 logo 给项目里的图贴胸口 logo

技能会依次完成：扫描目录结构 → 按款式确定 logo 尺寸比例 → 逐图判断能否贴并定位 → 批量覆盖原图 → 输出处理清单（贴了哪些、跳过了哪些及原因）。

也可以只处理单张图片：

```bash
python scripts/place_logo.py --logo logo.png --image shirt.jpg --inplace \
    --center 0.60,0.29 --shirt-w 0.72 --angle 0
```

## 依赖

Python 3.9+，仅需 `Pillow` 与 `numpy`。脚本按「只在 logo 外扩区域内运算」实现，处理大图时内存占用很小。

## 实现要点

- logo 按四点做透视贴合，可表达任意旋转与倾斜；
- 读取贴合区域的衣服明暗分布，让 logo 轻微跟随面料起伏，避免「贴纸感」；
- 按底色明暗自动选择混合方式，深色面料上的白 logo 走滤色、浅色面料上的深色 logo 走正片叠底；
- 边缘做亚像素羽化，避免硬边；
- 合成范围严格限制在 logo 包围盒内外扩少量像素，框外像素零改动。
