### 关键结论

- **位置 = 穿衣人左胸**：九张成品图里八张的 logo 落在观者视角的**右半边**；
  唯一在左半边的是第 3 张——那是衣服前片被摊开展示，贴的仍是同一块布。
  用户原话：「是穿衣人左胸，所以是现在衣服的右半边」。
- **水平位置**：logo 中心落在衣服横向宽度的 **0.62–0.70 W**（从左边缘量起）；
  两批数据合起来覆盖 0.57–0.74 W，默认取 **0.65 W**。
  **绝不允许落在 0.45–0.55 W（正中央）**——这是用户反馈过的问题。
- **垂直位置**：logo 中心位于领口最高点下方 **0.28–0.37 W**，跨越多组仍然稳定。

- **尺寸跟着衣服走**：组 7 下行两件显示得比上行大一倍，logo 也从 25px 变 28px；
  组 8 同图两件 33px 对 25px。若按图片宽度取比例（组 7 上行 3.1% / 下行 3.5%、组 2 为 2.4%），
  这些差异无法解释。
- **比例区间 4.5%–10%，多数在 8%–9%**：组 6 偏小是用户手工调的结果（用户已确认属于人为浮动），
  技能默认取 0.088，同一款式内固定使用同一个值。
- **同款不同色必须一致**：组 7 的 9.5%–10.0%、组 4/5 的 8.6%/9.8% 就是用户期望的水平。

## 二、怎么估这些量

1. **衣宽 W**：在图片里量衣服「含袖」的横向可见范围（左袖外缘到右袖外缘）。
   背景干净的平铺图可用亮度阈值自动分割（见下），模特图/复杂背景靠视觉判断。
2. **领口最高点**：立领取领子上缘最高处；翻领取领尖根部；领口被裁切时改用肩线。
3. **角度**：看衣服前片在画面里的倾斜方向。平铺/挂拍/正面模特一般为 0°；
   掀开、托举、侧身展示时常有 5°–15° 的倾斜，logo 必须同步旋转，否则会显得「贴歪」。
4. **辅助手段**：`scripts/grid_overlay.py` 会在图上叠百分比网格，便于直接读出归一化坐标；
   然后 `--center` 用归一化值、`--shirt-w` 也用归一化值即可，无需换算像素。
5. **水平定位**：先量出衣服左边缘 x0 与衣宽 W，logo 中心取 `x0 + 0.65 × W`；
   如果衣服有门襟（拉链 / 纽扣列），再校验一次——logo 中心应在门襟右侧约 0.15 W。
   把 `shirt_x0` 一起写进 plan，脚本会在报告里回显算出的百分比，方便自检。

背景干净时的自动量取（示例，可临时使用）：

```python
import numpy as np
from PIL import Image
a = np.asarray(Image.open("flat.jpg").convert("L"))
band = a[y0:y1] < 200            # 深色衣服 / 浅色背景
cols = np.where(band.sum(axis=0) >= (y1 - y0) * 0.05)[0]
print(cols.min(), cols.max(), cols.max() - cols.min() + 1)   # 即为 x 范围与 W
```

## 三、合成参数

`place_logo.py` 的默认值已经按示例调过，一般不用改：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `mode` | `auto` | 按底色明暗自动选混合（深色底走 screen、浅色底走 multiply、其余 normal） |
| `light_follow` | 0.5 | 让 logo 跟随衣服局部的明暗起伏，避免贴纸感 |
| `texture_keep` | 0.10 | 把衣服面料的高频纹理轻微叠到 logo 上 |
| `feather` | 自动 | 边缘羽化约 span/160，最小 0.5px |
| `opacity` | 1.0 | 不透明度；只在用户明确要求「淡化」时才调 |

需要绝对保色（例如客户要求 logo 颜色一比一）时，把 `mode` 设为 `normal` 并降低
`light_follow`、`texture_keep`，但会略微增加「贴纸感」。

## 四、常见坑

- **不要按图片宽度定尺寸**：这是最容易犯的错，八组数据都不支持。
- **不要贴到胸口正中央**：logo 中心应落在衣服横向 **0.62–0.70 W**（从左边缘量起）；
  如果算出来在 0.45–0.55 W 就是错的，必须重算。这是用户实际反馈过的问题。
- **不要用固定的画面坐标**：同一款衣服在不同展示方式下位置差异极大（组 3 与组 1 相差半个画面）。
- **背面图必须跳过**：组 8 中背面展示图没有贴。
- **衣服自带的徽章/印花不是 logo**：不要动它们，也不要把用户 logo 贴在其上。
- **同屏多件要逐件写落位**：一件图里 3–4 件衣服时用 `placements` 数组。
- **裁切图照常处理**：衣服被画面裁掉下摆时，仍按「领口 + 衣宽」定位。
- **浅色面料 + 白色 logo** 目前不做特殊处理（用户要求先观察实际效果）。
