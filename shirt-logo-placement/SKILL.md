# 服装图批量贴 logo

把用户当次提供的 logo 贴到服装商品图的**胸口**位置。整条流程只做**局部像素合成**：
衣服的颜色、款式、面料质感、褶皱明暗，以及背景、图中的文字与尺码表、其他衣服、
衣服上已有的装饰，全部保持原像素不变，只新增 logo 图层。

## 铁律

1. **严格等比缩放**：保持 logo 素材的宽高比，只调整大小，绝不拉伸变形。
2. **只动 logo 那一小块**：合成框外的像素必须一个都不改（这是用户验收的核心指标）。
3. **位置固定在「穿衣人左胸」**：衣服横向 0.62–0.70 W 处（从左边缘量起），
   绝不要贴到胸口正中央——这是最容易犯的错，判定方法见「落位规则」。
4. **同款一致**：同一个款式文件夹下的所有图片（主图 + 详情图），logo 相对衣服的大小
   必须一致——用同一个 `ratio`（logo 宽 ÷ 衣服宽）参数；位置则按每张图**单独判断**。
5. **原地替换**：默认覆盖原图（`--inplace`），用户自行备份，不需要额外备份机制。
6. **logo 用当次提供的那一张**，整个项目统一使用，不区分款式。

## 落位规则

位置的含义始终是「**穿衣人的左胸**」——衣服前襟上、门襟左侧（穿衣人视角）的那一块布。
在正面视图里它出现在**画面右半边**；衣服被翻折、摊开展示时会跑到画面另一侧，
但贴的永远是同一块布。

以**衣服横向宽度 W** 作为唯一尺度基准（按图片宽度取比例解释不了任何一组实测数据）：

| 项目 | 取值 |
| --- | --- |
| logo 宽度 | **0.085–0.09 × W**（默认 0.088） |
| 水平位置 | logo 中心落在衣服横向 **0.62–0.70 W** 处（从左边缘量起），即衣服中线偏右 0.12–0.20 W；等价说法：门襟右侧约 0.15 W |
| 垂直位置 | logo 中心在衣服领口最高点下方约 **0.28–0.37 × W** |
| 朝向 | 跟随衣服平面：衣服在画面里倾斜多少，logo 就转多少（示例中约 5°–10°） |

**最容易犯的错是贴到胸口正中央**。自检标准：logo 中心必须明显偏离衣服中线，
落在衣服左边缘到右边缘之间的 62%–70% 位置；如果算出来在 45%–55%，就是错的，必须重算。

### 怎么判断「哪一边是穿衣人左侧」

- **正面朝向镜头**（挂拍、平铺、模特正面）：穿衣人左侧 = 画面**右半边**。
  先找门襟（拉链 / 纽扣列），logo 落在门襟的右边、两者相距约 0.15 W。
- **背面或侧身展示、衣服前片被掀开或摊到一侧**：前片被翻折过来，
  穿衣人左胸那片布会出现在画面的**左半边**。这时跟着那块**前片**走——先认出前片的
  门襟边缘，logo 仍贴在同一块前片上，方向随前片倾斜。
- **胸口布料被手托举展示**：位置定义不变，只是画面坐标整体偏移，按衣服结构定位。

判定一律以**衣服结构**（领口、门襟、袖窿、前片边界、衣宽）为参照，不要用固定的画面
百分比坐标，也不要死记左右。示例实测数据见
[references/placement-rules.md](references/placement-rules.md)。

## 哪些图片跳过

跳过并在报告里写明理由：

1. **背面展示图**——看不到正面胸口 logo；
2. **局部特写**——只拍领口、袖口、拉链、口袋、面料，画面里没有胸口区域；
3. **纯文字 / 参数图**——尺码表、面料说明、价格，没有可贴的衣服；
4. **胸前已被占用**——衣服本身已有品牌 logo、印花或图案，位置会撞车；
5. **非上衣**——裤子、包、鞋、配饰；模特全身但上衣小到看不清胸口；
6. **胸口被遮挡**——被手臂、道具、水印、文字压住大半，或角度太侧、胸口几乎不可见。

以下情况**不要误跳过**：一件图里有多件同款（每件都要贴）、被画面裁掉一半的衣服、
各种展示方式（平铺、挂拍、模特上身、掀开、托举）。

## 流程

1. **确认输入**：logo 素材路径、项目根目录。若用户没说，先问清项目根目录。
2. **摸清结构**：扫描根目录，理清「款式文件夹 → 主图 / 详情图 子文件夹 → 图片」的层次。
3. **按款式定尺寸**：为每个款式估算衣服宽度 W 与适用的 `ratio`。
   需要精确落位时用 `grid_overlay.py` 生成带百分比网格的预览图辅助读数。
4. **逐图定位**：判断每张图能否加（跳过规则），估出 `center`、`shirt_w`、`angle`。
5. **写 plan.json** 并批量执行 `place_logo.py --inplace`。
6. **抽查结果**：用 `contact_sheet.py` 生成总览图，配合逐图查看确认没有贴歪、没漏、没错贴。
7. **报告**：说明处理了哪些款式、多少张成功、哪些跳过及原因。

## 工具

`scripts/place_logo.py`（核心，见文件头部注释里的完整参数与 plan.json 格式）：

```bash
# 项目级批量、就地覆盖
python place_logo.py --logo logo.png --root <项目根目录> --plan plan.json --inplace

# 先看不覆盖：输出到别处，保持相对目录结构
python place_logo.py --logo logo.png --root <项目根目录> --plan plan.json --out out/

# 单张
python place_logo.py --logo logo.png --image a.jpg --inplace \
    --center auto,0.29 --shirt-x0 0.08 --shirt-w 0.87 --angle 0
```

plan.json 里同款统一用同一个 `ratio`，并把该款所有图片都列上；一张图有多件衣服时用
`placements` 数组：

```json
{
  "defaults": {"ratio": 0.088},
  "款式A/主图/01.jpg": {"center": ["auto", 0.29], "shirt_x0": 0.08, "shirt_w": 0.87},
  "款式A/详情图/02.jpg": {"placements": [
      {"center": ["auto", 0.36], "shirt_x0": 0.04, "shirt_w": 0.29},
      {"center": ["auto", 0.36], "shirt_x0": 0.62, "shirt_w": 0.29}]},
  "款式A/详情图/03.jpg": {"skip": true, "reason": "背面展示图"}
}
```

**推荐写法**：横向位置用 `"center": ["auto", 纵坐标]` 交给脚本算——它会放在
`shirt_x0 + 0.65 × shirt_w`（即衣服横向 65% 处），比手算更不容易贴到中间；
需要微调时改 `ratio_x`（默认 0.65）。

`shirt_x0` 与 `shirt_w` 同时给出时，报告里会回显 `logo_center_ratio_in_shirt`；
该值跌到 0.55 以下（贴到胸口正中央）或超过 0.78（过分靠边）会附 `warning`，
批量跑完请扫一眼有没有 warning。

`scripts/grid_overlay.py` 生成百分比网格预览，供读数：

```bash
python grid_overlay.py 主图/01.jpg grid_01.png --max-size 1200
```

`scripts/contact_sheet.py` 把一批结果拼成总览图，便于一次核验：

```bash
python contact_sheet.py <目录或若干图片> --out sheet.png --cols 4
```

## 验收标准

- logo 框外像素零改动（可用前后差分验证）；
- logo 中心落在衣服横向 0.62–0.70 W，没有贴到正中央（报告里的
  `logo_center_ratio_in_shirt` 无 warning）；
- 同款各图 logo 相对大小一致（换算成 logo 宽 / 衣宽，误差 <10%）；
- logo 保持素材原本的比例与颜色，无拉伸、无描边、无换色；
- 该跳过的图确实没贴、该贴的图一处不漏。
